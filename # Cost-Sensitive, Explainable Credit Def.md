# Cost-Sensitive, Explainable Credit Default Prediction

Final-year dissertation project (BSc Data Science, Miva Open University).

## Data
SuperLender loan data from the Zindi "Data Science Nigeria 2019 Challenge #1".
Download `trainperf.csv`, `traindemographics.csv` and `trainprevloans.csv`
from Zindi and place them in the project root. They are not redistributed here.

Nigerian state boundaries: GADM v4.1, level 1 (`gadm41_NGA_1.json`),
downloadable from https://gadm.org.

## Notebooks
- `01_data_exploration.ipynb` — merging, data quality, feature derivation, train/val/test split

## Environment
Python 3.13.7. See `requirements.txt`.
